# Ismail Fekri & Partners

A bilingual, editorial-style corporate website for an independent advisory firm. Built with Next.js 16, React 19, TypeScript, Framer Motion, GSAP, and Lenis.

## Highlights

- English and Arabic routes with complete RTL support
- Responsive navigation with active-section feedback and scroll progress
- Smooth anchor navigation with a reduced-motion fallback
- Responsive editorial layouts for desktop, tablet, and mobile
- Locally optimized architectural photography with source credits

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`. The root route selects `/en` or `/ar` from the browser language.

## Production checks

```bash
npm run type-check
npm run build
npm start
```
